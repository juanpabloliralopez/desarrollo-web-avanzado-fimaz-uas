# Práctica 4 / LIRA LOPEZ 

## Objetivo
Construir un sistema de gestión de usuarios aplicando los pilares de la Programación Orientada a Objetos: Encapsulamiento, Herencia y Polimorfismo. Además de implementar el manejo de errores mediante excepciones.

## Estructura de Archivos
* `clases/`: Contiene las definiciones de Usuario, Admin, Alumno e Invitado.
* `index.php`: Archivo principal que genera la tabla y captura excepciones.

## Ruta de Ejecución
En el navegador, ingresar a:
`http://localhost/desarrollo-web-avanzado-fimaz-uas-main/parcial-1-poo/practica-4/index.php`

## Evidencia Esperada
se muestra una tabla html con los usuarios creados y un mensaje de "Error controlado" al intentar registrar un usuario con correo inválido.
